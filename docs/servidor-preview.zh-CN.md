# 进入 preview 服务器（官方测试服务器）

**preview 服务器**是 Pelican 4Ever 的官方存档，在测试阶段向测试者和协作者
开放。它是一个**真实且持久**的服务器：时钟与真实时间 1:1 对应，
每天在 02:00 自动换日，而且你下线后存档也不会重启。

> **preview 服务器要求完整的模组包，且必须是精确版本。** 它并不是一个
> "开放"的服务器：如果你缺少某个模组或版本不一致，服务器会在你进入时把你踢出。

相关文档：[despliegue/cliente.zh-CN.md](despliegue/cliente.zh-CN.md)（完整的客户端指南）

## 2. 分步操作

### 第 1 步 · 加入 Discord

加入官方 Discord 服务器：<https://discord.gg/2x5RuvvQB>

测试时段、模组包的版本变更都会在那里公布，错误报告也在那里收集。

### 第 2 步 · 安装模组和模组包

把 `Pelican4Ever 0.2.0.zip` 解压到你的 `Mods/` 文件夹内部，并按上面表格中的
**精确版本**安装模组包的其余部分。路径与权限的细节见
[despliegue/cliente.zh-CN.md](despliegue/cliente.zh-CN.md)。

### 第 3 步 · 通过直连 IP 连接

在游戏中：**合作 → 加入局域网游戏**（*直接连接*），填入 Discord 中给出的
**preview 服务器的 IP 和端口**。

### 第 4 步 · 首次尝试：指纹

服务器受设备白名单保护。首次尝试时：

1. 模组会生成（或已经有了）你的密钥，位于 `Mods/Pelican4Ever/data/device_key.json`。
2. 加密握手（`P4E\x02`）验证你的密钥是真实的。
3. 由于你的设备未获授权，服务器会**登记该请求并断开你的连接**，
   同时显示你的**短公钥指纹**：12 位十六进制，例如 `a1b2c3d4e5f6`。

### 第 5 步 · 请求批准

在 Discord 上给 **Dextrure** 发**私信（DM）**：

- 你的玩家名或别名，
- 你的 **12 位十六进制短指纹**。

批准是**永久性**的：它绑定到你的设备密钥，而不是你的 IP。你可以换路由器、
使用动态 IP 再次进入，无需重新配对。

### 第 6 步 · 进入

用相同的 IP 和端口再次选择*直接连接*。这次服务器会识别你的指纹，并
打开**农场工选择界面**：

- **新测试者：** 任选一个空闲槽位。它会永久且专有地绑定到
  你的设备。
- **其他玩家的槽位：** 会灰显并带有 `[De otro jugador]` 标签，点击
  被禁用。

如果你有一个之前使用过的角色（例如你来自封闭测试阶段），
向房主索要，让他把它绑定到你的新指纹。

## 3. 需要测试的内容

这是一个测试阶段：你反馈的内容都会进入待办列表。值得观察的有：

| 系统 | 需要观察 |
| --- | --- |
| **1:1 时钟** | 游戏内时间与真实时间一致（1 个真实日 = 1 个游戏日） |
| **深夜冻结（NightHold）** | 在 **01:50** 到 **06:00** 之间时钟冻结在 `2550`：可以在夜里游玩而不会晕倒 |
| **换日** | 在 **02:00** 日期推进；HUD 上提前 10 分钟提醒，并有音效提示 |
| **居所** | 中央广场以及向东的桥梁通往 16 处居所；每位邻居都有农场（8 种类型）和私人洞穴；`/residencia` 可更改权限（`关闭`、`仅好友`、`公开`） |
| **异步休息** | 你可以上床睡觉并退到菜单，不会暂停世界，也不会把任何人赶出去 |
| **饱腹值与「吃饱」增益** | 吃任何食物都会提升该栏；饱腹值 ≥ 1/4 时，「吃饱」增益允许坐着恢复精力 |
| **温泉** | 造访温泉水道可在 2 个真实小时内最多恢复 120 点精力和生命值 |
| **邻里集市** | 买卖农作物和手工产品，即使买家已离线也能完成结算 |
| **聊天** | `/g` 全局，`/l` 邻近，`/w` 私语 |
| **NITV 野生动物** | 16 处居所、广场和桥梁上的动物与昆虫（需要兼容扩展包） |
| **宠物** | 从客户端的**动物**标签页收集和领养宠物 |

## 4. preview 上的常见问题

### 我一进去就被踢出

这是**模组包**的问题：服务器要求每个模组都使用精确版本，并在初始握手时把你踢出。
服务器日志会给出确切原因（`player.rejected`）：

- `没有服务器要求的模组包：缺少 <ID> <版本>。` → 缺少该模组。
- `没有服务器要求的模组包：<ID> <你的版本>（服务器使用 <版本>）。` → 版本
  不一致。
- `未使用 SMAPI。` → 你没用 SMAPI 启动游戏。
- `版本不兼容（……）` → 你的模组版本不一致（按 *major.minor* 比较）。

### 「服务器受白名单保护……」

你的 IP 没有任何有效邀请。在再次尝试之前，先到 Discord 上申请：
如果你的 IP 是共享的（家庭、公司、学校），可能有另一个指纹占用了邀请。

### 「你的 IP 的所有邀请都已被占用……」

已经有来自你 IP 的另一个指纹的待处理请求。等待对方批准，或向房主
申请一份带你的别名的新邀请。

### 他们换了我的 IP，现在进不去

指纹不依赖 IP：一旦获批，你就一直能进入。如果被踢出，问题在于模组版本，
或者服务器重启时重新加载了白名单：到 Discord 上询问。

### 我换了电脑

把 `Mods/Pelican4Ever/data/device_key.json` 复制到新设备，你就会凭同一份
批准进入。如果文件不在了，请让对方把你的新指纹绑定到你的角色。

### 游戏很卡或我掉线了

- 服务器是持久运行的，负载由它承担；如果你的设备很卡，请检查你的图形设置。
- 偶尔掉线在家庭网络中很正常：世界继续运行，你凭同一指纹再次
  进入即可。
