# 客户端模式：在 Pelican 4Ever 服务器上游玩

指南：在你的设备（PC、Steam Deck，或你使用的任何设备）上安装模组并进入 Pelican
4Ever 服务器：官方测试服务器，或你自己托管的服务器。

相关文档：[servidor-preview.md](../servidor-preview.zh-CN.md)（进入官方测试
服务器）· [host-local.md](host-local.zh-CN.md) · [host-vps.md](host-vps.zh-CN.md)

---

## 1. 要求

| 项目 | 版本 |
| --- | --- |
| Stardew Valley | 1.6.15（Steam 或 GOG） |
| SMAPI | 4.1 或更高（推荐 4.1.10+） |
| Pelican 4Ever | 0.2.0（与服务器相同的 *major.minor*） |
| 模组包 | 与服务器相同的模组包，且**版本完全相同** |

游戏**始终通过 SMAPI** 启动，绝不要用普通可执行文件。

---

## 2. 必需的模组包

服务器会在初始握手时检查客户端是否声明了**完整的模组包，且为精确版本**。
如果缺少某个模组或版本不一致，服务器会在握手过程中踢出客户端，
你就无法进入。

- 向主机索取他使用的模组包（或模组及其版本列表），并**按这些精确版本**安装：
  比较的是完整版本，而不是 *major.minor*。
- 如果主机更新了模组包中的某个模组，你也必须更新到完全相同的精确版本，
  否则将无法进入。
- 服务器**没有**安装的模组不会被要求；你多装的模组也不会被
  检查。
- 模组包由哪些模组组成及其版本的细节见
  [../servidor-preview.md](../servidor-preview.zh-CN.md)。

---

## 3. 安装

1. 把 `Pelican4Ever` 文件夹（从 ZIP `Pelican4Ever 0.2.0.zip` 解压而来）复制到
   `Mods/` 内部：
   - **Linux / Steam Deck：** `~/.steam/steam/steamapps/common/Stardew Valley/Mods/`
     （或 `~/.local/share/Steam/steamapps/common/Stardew Valley/Mods/`）
   - **Windows：** `C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley\Mods\`
2. 把模组包的其余部分也装到同一个 `Mods/` 文件夹（每个模组一个文件夹），使用
   服务器所用的精确版本。
3. 确认存在 `.../Mods/Pelican4Ever/manifest.json`。
4. **不要复制服务器的 `config.json`**：在客户端你可以删掉自动生成的配置，SMAPI
   会用默认值重建它。在客户端只有网络选项有意义；主机端选项
   （`AutoHostSaveName`、`RestartExitsProcess`、`HeadlessRendering`）不适用。

### 3.1 首次启动与密钥

通过 SMAPI 启动游戏。模组会在以下位置生成你的加密密钥对：

```
Mods/Pelican4Ever/data/device_key.json
```

在 Linux 和 macOS 上，模组会自动把该文件权限设为 `0600`（你的私钥
不应对其他用户可读）。

---

## 4. 连接服务器

1. 在主菜单：**合作 → 加入局域网游戏**（*直接连接*）。
2. 填入主机给你的 **IP 和端口**（默认 `24642`）。
   - 没有打开 Steam 就没有邀请码：始终通过 IP 进入。
3. 初始握手是加密的（`P4E\x02`）：服务器会向你发送一个 30 秒有效的临时
   质询，你的客户端用你的私钥签名。**你的私钥和任何可复用的 token
   都不会**通过游戏通道传输。

### 4.1 首次接触：配对

第一次连接时，服务器会校验你的**指纹**（你公钥的 SHA-256）。由于你尚未
获得授权，它会干净地断开连接，并向你显示类似下面的内容：

> 设备已登记待批准。指纹：a1b2c3d4e5f6。请让所有者在 Discord 上批准
> 你的访问。

根据白名单的状态，你可能会看到以下不同提示：

| 提示信息 | 含义 | 应对方式 |
| --- | --- | --- |
| `设备已登记待批准。指纹：……` | 你的请求处于待处理状态 | 把指纹发给主机，等待他批准 |
| `服务器受白名单保护。请在 Discord 上向所有者申请邀请。` | 你的 IP 没有任何邀请 | 请主机为你的 IP 创建邀请 |
| `你的 IP 的所有邀请都已被其他待处理请求占用。` | 你的 IP 确有邀请，但已被另一个指纹占用 | 为你的别名申请新邀请，或让他批准待处理的那个 |

**指纹不依赖你的 IP**：即使换了 IP 或重启路由器，你依然凭同一份批准进入。

获批之后，你重新点击*直接连接*，进入农场工选择界面：

- **空闲**的农场工可以选择：它们会永久绑定到你的设备。
- **其他玩家**的农场工会灰显，带有 `[De otro jugador]` 标签，且
  点击被禁用。

## 5. 你能在游戏里做什么

| 命令 | 作用 |
| --- | --- |
| `/g <消息>` | 服务器全局聊天 |
| `/l <消息>` | 邻近范围的本地聊天（只有附近的人能听到） |
| `/w <玩家> <消息>` | 对另一位邻居的悄悄话 |
| `/residencia` | 你自己居所的权限：`关闭`、`仅好友`、`公开`、好友列表以及带工具的访问权限 |
| `/evento empezar` | 报名参加当天的节庆批次 |

中央广场（`Farm`）是主地图：从那里经过向东的桥梁，就是通往 16 处私人
居所的传送门。每位邻居都有自己的农场（8 种官方类型）和自己的私人洞穴。

## 6. 常见问题

### 「我一进去就被踢出」

服务器会在初始握手时检查你的模组和模组包版本，并在日志中给出确切的
踢出原因（`player.rejected`）。常见原因：

| 服务器日志中的原因 | 解决方案 |
| --- | --- |
| `未使用 SMAPI。` | 通过 SMAPI 启动游戏，而不是普通可执行文件 |
| `未安装 Pelican 4Ever。` | 缺少 `Mods/Pelican4Ever` 文件夹 |
| `版本不兼容（0.1.0；服务器使用 0.2.0）。` | 模组自身的比较依据是 *major.minor*：重新安装服务器所用的版本 |
| `没有服务器要求的模组包：缺少 <ID> <版本>。` | 缺少该模组：**按该精确版本**安装 |
| `没有服务器要求的模组包：<ID> <你的版本>（服务器使用 <版本>）。` | 版本不一致：把你的版本对齐到服务器的版本 |

> 客户端不会收到有说明性的提示：服务器会直接把你踢出。因此首先要看的是
> 客户端的指纹。

### 「我换了电脑或重装了系统」

把 `Mods/Pelican4Ever/data/device_key.json` 复制到新设备：你的身份随你同行，
你依然凭同一份批准进入。如果没有该文件，请主机把你的新指纹绑定到你的角色
（`p4e_migrate_player <huella> <peón>`）。

### 「之前能进，现在进不去」

- 你是不是无意中更新了模组包里的某个模组？版本必须**完全一致**。
- 服务器是不是重启并更换了白名单？请你的主机查看
  `p4e_pair_list`。
- 如果你的 IP 是共享的（公司或家庭 NAT），可能有其他指纹占用了邀请。

### 「游戏很卡」

服务器承担重活（模拟和网络）；你的设备只负责绘制。如果很卡，请检查
你的图形设置和你使用的模组，而不是存档本身。

---

## 7. 卸载

删除 `Mods/Pelican4Ever` 文件夹（如果模组包没有别的用途，也可以一并删除）。
删除 `Mods/Pelican4Ever/data/device_key.json` 会生成新的身份：服务器会
把它视为未授权设备，你必须重新配对。
